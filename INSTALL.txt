RUFUSTHEDWARF PROFILE README PACK
=================================

Contents
--------
README.md                 Complete GitHub profile README
assets/header.svg         Animated profile header
assets/about.svg          Animated About section banner
assets/skills.svg         Animated skills / technology matrix
assets/footer.svg         Animated profile footer

Install
-------
1. Download and extract this archive.
2. Copy README.md and the complete assets/ folder into the root of:
   https://github.com/RufusTheDwarf/RufusTheDwarf
3. Keep the folder name exactly "assets". The README uses relative paths.
4. Preview the profile page before committing.

Important
---------
- These SVG files are self-contained. They use inline vector shapes, gradients,
  CSS keyframes and no external image assets or JavaScript.
- Animation is intended to play when GitHub displays the SVGs as images.
  SVG animation support can vary between renderers and cached previews.
- The README is supplied as a separate file in this archive.
- No changes have been made to your GitHub repository.
